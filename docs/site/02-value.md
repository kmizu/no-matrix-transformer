# 第2章 微分できる数 `Value`

言語モデルの学習は「損失を小さくする方向にパラメータを少し動かす」ことの繰り返しです。
「どの方向に動かせばいいか」を知るには、損失をパラメータで**微分**する必要があります。

パラメータは数千個。手で微分するわけにはいきません。
そこで、**計算しながら微分の材料を記録する数**を作ります。これが `Value` です。

## 考え方: 傾きを持ち歩く

普通の数 `3.0` は、ただの `3.0` です。
`Value(3.0)` は、「3.0 という値」に加えて、「自分がどのノードから、どれだけの傾きで作られたか」を覚えています。

たとえば \( c = a \times b \) なら、\( \partial c / \partial a = b \)、\( \partial c / \partial b = a \) です。
この「局所的な傾き」は掛け算した時点で分かるので、`c` にそのまま記録しておきます。

```scala mdoc
import nomatrix.autograd.Value

val a = Value(2.0)
val b = Value(3.0)
val c = a * b
c.inputs.map((in, slope) => (in.data, slope))
```

`c` は「`a`（値 2.0）から傾き 3.0 で、`b`（値 3.0）から傾き 2.0 で作られた」と覚えています。

## 逆伝播: 傾きを後ろから配る

最終的な結果（損失）から出発して、記録された傾きを掛けながら入力側へ配っていくと、
すべてのノードについて「損失をそのノードで微分した値」が求まります。これが**逆伝播**、
数学でいう**連鎖律**です。

```scala mdoc
val y = a * b + a          // y = a*b + a
val grads = Value.gradients(y)
grads(a)                   // dy/da = b + 1 = 4
grads(b)                   // dy/db = a = 2
```

`a` は 2 回使われています（`a * b` と `+ a`）。逆伝播は、両方の経路から来た傾きを足し合わせます。

## 数値微分で答え合わせ

本当に正しい微分になっているか、\( (f(x+h) - f(x-h)) / 2h \) で確かめてみます。

```scala mdoc
def f(x: Double): Double = math.tanh(x * x + math.exp(x))
def fv(x: Value): Value = (x * x + x.exp).tanh

val x0 = 0.3
val h = 1e-5
val numeric = (f(x0 + h) - f(x0 - h)) / (2 * h)

val x = Value(x0)
val auto = Value.gradients(fv(x))(x)

math.abs(numeric - auto) < 1e-6
```

## 実装を読む

`Value` の全体です。行列はもちろん、配列すら使っていません。

```scala
--8<-- "src/main/scala/nomatrix/autograd/Value.scala"
```

読みどころは 3 つです。

**1. ノードは不変（immutable）**
`data` と `inputs` はコンストラクタで確定し、以後変わりません。
逆伝播の結果は `Gradients` という別のオブジェクトに入ります。
「勾配をノードに書き戻す」設計にしないことで、同じグラフから何度でも安全に微分できます。

**2. `Value.sum` はひとつのノード**
1000 個の数を `+` で順に足すと、深さ 1000 のグラフになります。
`sum` は「入力が 1000 個あるノードひとつ」にするので、グラフが浅く保たれ、後の内積が軽くなります。

**3. 再帰を使わない**
`topologicalOrder` は明示的なスタックで深さ優先探索します。
Transformer のグラフは数万ノードになるので、再帰だとスタックがあふれます。

## テスト

`ValueTest` では、加減乗除・`exp`・`log`・`tanh`・`relu`・`pow` それぞれの微分を数値微分と突き合わせ、
深さ 20,000 のグラフでもスタックオーバーフローしないことを確認しています。

!!! tip "この章のまとめ"
    - `Value` = 値 + 「誰からどれだけの傾きで作られたか」
    - `Value.gradients(root)` で、すべてのノードの微分が一度に求まる
