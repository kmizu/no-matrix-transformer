## 第3ラウンドの実測

同じモデル・同じコーパス・2000 ステップ。損失は評価用に固定した 64 窓（同じコーパスから、学習の窓とは別に引いたもの）の平均。
「基準」は第14章で最良だった「ゼロ初期化 ＋ 一段ずつ育てる ＋ 歩幅の探索」（1.67）。素の基本形は 1.81。

| 試したこと | 2000 ステップの損失 | 判定 |
|---|---:|---|
| 基準（ゼロ初期化 ＋ 一段ずつ ＋ 歩幅探索） | 1.67 | – |
| 基準 ＋ 出力バイアスを頻度で初期化 | 1.70 | 序盤だけ速い |
| 基準 ＋ 学習率の減衰 ＋ 反復平均 | 1.69 | 同等 |
| 基準 ＋ ±1 のゆらぎ | 1.73 | やや悪化 |
| 基準 ＋ ゆらぎの直交化 | 1.62 | 改善 |
| 基準 ＋ 方向ごとの曲率 | 2.22 | 悪化 |
| 基準 ＋ 頻度初期化 ＋ 減衰 ＋ 平均 | 1.67 | 同等 |
| 基準を 32 対 × 16 窓に | 1.76 | 悪化 |
| ゼロ初期化 ＋ 歩幅探索 ＋ **ブロックごとの局所損失** | **1.53** | 改善（最大） |
| 上 ＋ 直交化 | 1.56 | 同等（ばらつきの範囲） |
| 上 ＋ 直交化 ＋ 頻度初期化 ＋ 減衰 | **1.45** | 改善（最良） |
| 評価の並列化（16 論理コア） | 同じ結果 | 1.8 倍速い |
| （参考）逆伝播 + Adam、2000 ステップ | 1.01 | – |

局所損失は「各ブロックが自分の出力に仕上げを当てた損失で、前のブロックの出力は固定して、同時に育つ」形です。
ゆらぎで測る範囲が「モデル全体」から「ブロック 1 つぶん」に縮むので、同じ評価回数で向きの推定が良くなります。
これは壁の内側の工夫ではなく、計算の中（ブロックの境目）を少し見る工夫です。

## 最良レシピを 8000 ステップ回す

上の表で最良だった「ゼロ初期化 ＋ 歩幅探索 ＋ 局所損失 ＋ 直交化 ＋ 頻度初期化 ＋ 減衰」を、評価を並列化して 8000 ステップ回しました。
公平のため、逆伝播も同じ 8000 ステップ回しています。損失は同じ 64 窓で測ったものです。

| 学習法 | ステップ | 時間 | 損失 |
|---|---:|---:|---:|
| ゆらぎ学習（第13章の素の設定、1 コア） | 8,000 | 62 分 | 1.02 |
| ゆらぎ学習（最良レシピ、16 論理コアで並列） | 8,000 | 24 分 | **0.65** |
| 逆伝播 + Adam（1 コア） | 2,000 | 4 分 | 1.01 |
| 逆伝播 + Adam（1 コア） | 8,000 | 22 分 | **0.48** |

最良レシピの生成例（温度 0.5、プロンプト「あさ」）:

```text
あさ おきて おちゃを のむ。あたまが すぎる。
よる おふろに はいる。からだが あたまる。かぜが はいる。
```

同じステップ数で、素のゆらぎ学習と逆伝播の差 1.02 対 0.48 が、0.65 対 0.48 まで縮みました。
縮めたのは主に局所損失で、これは「ブロックの境目で計算の中を少し見る」工夫です。
それでも逆伝播には届かず、時間で並んだのは 16 コアを使ったからです。壁の位置は変わっていません。
